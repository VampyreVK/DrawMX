# DrawMX

A WIP drawing app for the Meta Quest 3 designed to utilize the latest in Meta's SDK features.

Designed for the [Logitech MX Ink](https://www.logitech.com/en-us/products/vr/mx-ink.html). (Currently, no regular controller support is availible)


# Resources
## Drawing Functionality
Built using help from the following tutorials:
* [MX Ink manager / Basic Drawing Functionality](https://www.youtube.com/watch?v=KCPEpbY5XQE&t)
* [Passthrough API / Color Picker Help](https://www.youtube.com/watch?v=1z3pcMJbnRA)

> [!NOTE] Tutorial Note
> The Code was heavily adjusted from the above tutorials to both work together and fit the design I had in mind for DrawMX, so these tutorials will not allow you to recreate this project 1-1, but they will give you a good idea of some of the basic concepts utilized.
